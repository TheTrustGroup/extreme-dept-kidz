# Color Usage Guidelines
## When to Use Navy vs Forest

**Purpose:** Define clear rules for when to use each accent color to ensure brand consistency and visual cohesion.

---

## 🎨 COLOR ROLES

### Navy 900 (#102a43) - Primary Accent

**Use for:**
- ✅ Primary CTAs (buttons, links)
- ✅ Navigation links and active states
- ✅ Primary text emphasis
- ✅ Headings that need emphasis
- ✅ Badges for primary actions (e.g., "SALE")
- ✅ Focus indicators and outlines
- ✅ Primary interactive elements

**Examples:**
- "Add to Cart" button
- "Shop Boys" CTA
- Navigation links
- Active filter chips
- Primary form submit buttons

**Do NOT use for:**
- ❌ Secondary actions
- ❌ Success states
- ❌ Background colors (too dark)
- ❌ Body text (use charcoal instead)

---

### Forest 600 (#277d47) - Secondary Accent

**Use for:**
- ✅ Secondary CTAs (alternative actions)
- ✅ Success states and confirmations
- ✅ Positive feedback indicators
- ✅ Trust badges and security indicators
- ✅ Secondary badges (e.g., "NEW", "FEATURED")
- ✅ Progress indicators
- ✅ Positive status messages

**Examples:**
- "Save for Later" button
- Success messages ("Item added to cart")
- Trust bar icons
- "In Stock" indicators
- Positive validation messages

**Do NOT use for:**
- ❌ Primary CTAs (use Navy)
- ❌ Error states (use red)
- ❌ Warning states (use yellow/orange)
- ❌ Navigation elements

---

## 📋 DECISION TREE

### Is it a primary action?
- **Yes** → Use **Navy 900**
- **No** → Continue to next question

### Is it a success/positive state?
- **Yes** → Use **Forest 600**
- **No** → Continue to next question

### Is it a secondary action?
- **Yes** → Use **Forest 600** or **Navy 800** (lighter Navy)
- **No** → Use **Charcoal** (neutral)

## 🚫 COMMON MISTAKES TO AVOID

### ❌ Don't Mix Colors Arbitrarily
- Don't use Forest for primary CTAs
- Don't use Navy for success states
- Don't use both colors in the same component without clear hierarchy

### ❌ Don't Use Colors for Body Text
- Use Charcoal 900 for headings
- Use Charcoal 700 for body text
- Use Charcoal 600 for labels/captions
- Only use Navy/Forest for emphasis or CTAs

### ❌ Don't Create New Accent Colors
- Stick to Navy (primary) and Forest (secondary)
- Don't introduce new accent colors
- Use neutrals (Cream, Charcoal) for backgrounds and text

---

## ✅ BEST PRACTICES

### 1. Maintain Visual Hierarchy
- Primary actions: Navy 900 (most prominent)
- Secondary actions: Forest 600 or Navy 800 (less prominent)
- Neutral elements: Charcoal (subtle)

### 2. Use Colors Consistently
- Same color for same function across the site
- Don't change colors based on page or section
- Maintain consistency in component variants

### 3. Consider Accessibility
- Ensure sufficient contrast (WCAG AA minimum)
- Navy 900 on Cream 50: ✅ 8.5:1 (AAA)
- Forest 600 on Cream 50: ✅ 4.8:1 (AA)
- Test with color blindness simulators

### 4. Use Neutrals for Structure
- Cream colors for backgrounds
- Charcoal colors for text
- Navy/Forest only for emphasis and actions

## 🔄 MIGRATION GUIDE

### If Currently Using Forest for Primary Actions
1. Identify all primary CTAs using Forest
2. Replace with Navy 900
3. Update hover states to Navy 800
4. Test visual hierarchy

### If Currently Using Navy for Success States
1. Identify all success indicators using Navy
2. Replace with Forest 600
3. Update related components
4. Test accessibility
