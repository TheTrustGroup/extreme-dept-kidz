# Frontend Design Principles

The goal is to make Extreme Dept Kidz world-class and polished while keeping familiar functionality.

### 1. Brand Focused Aesthetics
- Use a refined color palette (brand primary + neutrals)
- Avoid visual clutter
- Ensure premium look that matches luxury fashion positioning

### 2. Consistent Spacing & Rhythm
- Define a spacing scale (e.g., 8px–32px steps)
- Apply consistent margins and padding
- Unified grid system for pages

### 3. Typography Hierarchy
- Clear headings (H1, H2, H3), body text, button text
- Legible fonts, proper sizes for desktop and mobile
- Avoid overly decorative fonts that reduce readability

### 4. Interactive Feedback
- Micro-interactions on hover/tap
- Clear visual states (hover, focus, active)
- Animated loading states where appropriate

### 5. Mobile-First Mindset
- All desktop layouts scale down gracefully
- Touch-optimized buttons and interactions
- Simplify navigation for small screens
