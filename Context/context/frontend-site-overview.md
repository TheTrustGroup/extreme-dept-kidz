# Frontend Site Overview — Extreme Dept Kidz

The Extreme Dept Kidz website is a premium kids’ fashion storefront.  
It highlights collections, product categories (Boys, Girls, New Arrivals), and brand messaging focused on “elevated style for young legends.” The site includes navigation, calls to action, promotional messaging, and links to customer care (shipping, returns, size guide, etc.). :contentReference[oaicite:1]{index=1}

Primary goals for the enhancement project:
- Maintain the site’s current e-commerce functionality
- Preserve all live links, SEO, and business logic
- Upgrade visual design, layout rhythm, and visual hierarchy
- Improve clarity, professionalism, and user engagement

Important constraints:
- Do not delete or refactor core commerce functionality
- Changes must be backward-compatible and testable
- Maintain responsiveness on mobile, tablet, and desktop

This file represents the *North Star* vision for the UI refinement.
