# UX Improvement Notes

The aim is to refine the user experience while keeping user familiarity.

### Navigation
- Sticky or persistent header on scroll
- Clear menu labels with visible click/tap areas
- “Shop Boys”, “Shop Girls”, and “Collections” as primary CTAs

### Homepage Enhancements
- Strong hero section with clear brand message
- Featured collections visually segmented
- Strategic use of whitespace for breathing room

### Product Listings
- Hover states reveal quick “View” or “Add to cart” actions
- Rating or badges for featured products
- Filters/sorting with clear visual cues

### Footer & Help Links
- Visually distinct footer sections
- Accessible links for Shipping Info, Size Guide, etc.
- Social media icons styled with brand consistency
